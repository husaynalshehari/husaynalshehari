# الدخول برمز الدعوة

التطبيق مقفول، ولا يدخله إلا من أعطيته رمزاً.

## كيف يشتغل؟

1. أنت (المدير) تفتح **لوحة التحكم** `/admin` وتكتب اسم المستخدم.
2. يطلع لك **رمز دعوة** مثل `4YEG-49HK-PKEN` ومعه رسالة جاهزة فيها الرابط. انسخها وأرسلها للشخص (واتساب، إيميل…).
3. الشخص يفتح الرابط، ويكون الرمز مكتوباً تلقائياً، فيختار كلمة مرور ويضغط **تسجيل**.
4. بعدها يدخل من `/login` باسم المستخدم وكلمة المرور.

| الميزة | التفاصيل |
|---|---|
| الرمز يُستخدم مرة واحدة | بعد التسجيل يتعطل ولا يشتغل مع أحد ثاني |
| صلاحية الرمز | يوم / 3 أيام / أسبوع / شهر (تختار عند الإنشاء) |
| إيقاف مستخدم | زر **إيقاف**، ويخرج من التطبيق فوراً حتى لو كان داخل |
| نسي كلمة المرور | زر **رمز لإعادة تعيين كلمة المرور**، وترسل له رمزاً جديداً |
| الحماية من التخمين | بعد 10 محاولات خاطئة يُمنع الـ IP ربع ساعة |
| التخزين | كلمات المرور مشفّرة، والرموز محفوظة كبصمة فقط (ليست نصاً واضحاً) |

---

## التشغيل على جهازك (للتجربة)

```bash
pip install -r requirements.txt
python app.py create-admin      # مرة واحدة: تختار اسم وكلمة مرور المدير
python app.py                   # افتح http://127.0.0.1:5000
```

## التشغيل على الاستضافة

```bash
pip install -r requirements.txt
python app.py create-admin
gunicorn -w 2 -b 0.0.0.0:8000 app:app
```

> **مهم:** شغّل الموقع على **HTTPS** (أغلب الاستضافات توفره مجاناً)، وإلا تنتقل كلمات المرور بدون تشفير.

### متغيرات البيئة (اختيارية)

| المتغير | الفائدة | مثال |
|---|---|---|
| `APP_NAME` | اسم التطبيق اللي يظهر في الصفحات | `تطبيقي` |
| `PUBLIC_URL` | رابط موقعك، ويُستخدم في رابط التسجيل اللي ترسله | `https://myapp.com` |
| `SECRET_KEY` | مفتاح الجلسات (لو ما وضعته، يُنشأ تلقائياً في `instance/secret_key`) | نص عشوائي طويل |
| `DATA_DIR` | مكان حفظ قاعدة البيانات (الافتراضي مجلد `instance`) | `/var/data` |
| `TRUST_PROXY` | ضع `1` إذا التطبيق خلف Nginx أو بروكسي الاستضافة | `1` |
| `APP_TIMEZONE` | المنطقة الزمنية لعرض التواريخ | `Asia/Riyadh` |
| `ADMIN_USERNAME` و `ADMIN_PASSWORD` | لو استضافتك ما فيها Terminal: يُنشأ المدير تلقائياً أول تشغيل (احذفهما بعد أول تشغيل) | |

> بعض الاستضافات تمسح الملفات مع كل تحديث. تأكد أن مجلد `instance` (أو `DATA_DIR`) في مكان **دائم**، لأن فيه كل المستخدمين. وخذ نسخة احتياطية من `instance/app.db` بين فترة وأخرى.

نسيت كلمة مرور المدير؟ شغّل `python app.py create-admin` بنفس الاسم وتتغير كلمة المرور.

## حماية صفحاتك

أي صفحة تضيفها في `app.py` ضع فوقها `@login_required`، فلا يفتحها إلا مستخدم مسجّل:

```python
@app.route("/my-page")
@login_required
def my_page():
    return render_template("my_page.html")
```

وللصفحات الخاصة بك أنت فقط استخدم `@admin_required`.

الصفحة الرئيسية حالياً في `templates/dashboard.html`، وهي المكان اللي تحط فيه واجهة تطبيقك.
