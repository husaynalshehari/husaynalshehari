# نظام التراخيص

تطبيقك لا يشتغل إلا برمز تعطيه أنت.

- `license-server/server.py`: السيرفر ولوحة التحكم، يشتغل على استضافتك.
- `license_client.py`: يوضع داخل تطبيقك، ويسأل السيرفر عن الرمز عند كل تشغيل.

## كيف يشتغل؟

1. تفتح **لوحة التراخيص** على استضافتك، تكتب اسم المستخدم، وتضغط **إنشاء رمز**.
2. تنسخ الرمز (مثل `PPCG-8WYY-S4NE`) وترسله للمستخدم.
3. المستخدم يشغّل التطبيق، فيطلب منه رمز التفعيل. يكتبه مرة واحدة فقط، ويُحفظ على جهازه.
4. كل مرة يُفتح فيها التطبيق، يتأكد من السيرفر أن الرمز ما زال فعّالاً.

| من اللوحة تقدر | النتيجة |
|---|---|
| **إيقاف** | التطبيق يتوقف عند المستخدم من التشغيل التالي |
| **فك ربط الجهاز** | المستخدم غيّر جهازه، فتسمح له يفعّل الرمز على الجهاز الجديد |
| **رمز جديد** | لو انتشر الرمز: القديم يتوقف فوراً، وترسل له رمزاً جديداً |
| **حذف** | يُحذف المستخدم نهائياً |

**الرمز مربوط بالجهاز:** أول جهاز يفعّل الرمز يرتبط به، فلو أعطاه المستخدم لصديقه يظهر له: «هذا الرمز مفعّل على جهاز آخر».

## 1) تشغيل السيرفر على الاستضافة

```bash
cd license-server
pip install -r requirements.txt
gunicorn -w 2 -b 0.0.0.0:8787 server:app
```

أول تشغيل يطبع **كلمة مرور اللوحة** في السجل (log)، وتجدها أيضاً في الملف `license-server/data/admin_password.txt`.
للتجربة على جهازك يكفي: `python server.py` ثم افتح `http://127.0.0.1:8787`.

### متغيرات البيئة (اختيارية)

| المتغير | الفائدة |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور اللوحة بدل الكلمة العشوائية. لو غيّرتها، تنتهي كل الجلسات المفتوحة |
| `PORT` | المنفذ (الافتراضي `8787`) |
| `DATA_DIR` | مكان حفظ البيانات (الافتراضي `license-server/data`) |
| `TRUSTED_PROXIES` | عدد البروكسيات أمام السيرفر (Nginx = `1`، أو Cloudflare + Nginx = `2`). اتركه فارغاً إذا ما فيه بروكسي |
| `COOKIE_SECURE` | ضع `1` إذا الموقع على HTTPS (وهذا المفروض) |

> **مهم:**
> - استخدم **HTTPS**.
> - مجلد `data` فيه كل المستخدمين، فخذ منه نسخة احتياطية، وتأكد أن الاستضافة ما تمسحه مع التحديثات.
> - لو كان عندك السيرفر القديم شغالاً، انسخ مجلد `data` كما هو. المستخدمون والرموز تبقى، وتُضاف أعمدة الجهاز تلقائياً.

## 2) ربط تطبيقك بالسيرفر

انسخ `license_client.py` بجانب ملف تطبيقك، وعدّل فيه رابط السيرفر:

```python
LICENSE_SERVER = os.getenv("LICENSE_SERVER", "https://your-domain.com")
```

وفي بداية تطبيقك ضع:

```python
from license_client import require_license

require_license()   # لو الرمز غير صحيح، يقفل التطبيق هنا
# ... باقي التطبيق
```

لا يحتاج أي مكتبة إضافية.

### للمطورين: واجهة التحقق

```
POST /api/check
{"code": "PPCG-8WYY-S4NE", "device": "<بصمة الجهاز>", "device_name": "Windows · PC"}

← {"ok": true, "name": "خالد"}
← {"ok": false, "message": "الرمز غير مقبول."}
```

لو تطبيقك مكتوب بلغة غير Python، أرسل نفس الطلب منه.
