# خادم التحكّم (control_server.py)

خادم مستقل تشغّله على استضافتك. من صفحة واحدة (بكلمة مرور المالك):

- **رموز الدخول:** تنشئ رمزًا لكل مستخدم. لا يفتح التطبيق إلا برمز يعرفه الخادم ولم توقفه. تقدر توقف أي رمز فورًا.
  - **كل رمز يُربط بجهاز واحد:** أول جوال يُفعّله يُربط به؛ غيره بنفس الرمز يُرفض. زر «تحرير الجهاز» يفكّ الربط لنقله لجوال جديد.
  - **التكلفة لكل مستخدم وحساب:** لكل رمز عدد تعليقاته وتكلفتها (0.01 لكل تعليق)، وتفصيل لكل حساب X داخله.
- **المفاتيح:** تضع مفتاح Gemini ومفتاح Claude وتختار من يكتب التعليقات. المفاتيح تبقى **على الخادم** (مختومة على القرص) ولا تُرسل للأجهزة أبدًا. التطبيق يرسل نص التغريدة (وصورتها) فيُكتب الرد هنا ويُعاد إليه.

الخادم منفصل تمامًا عن خادم القروبات/المستخدمين الرئيسي؛ لم يُلمس شيء منه.

## التشغيل

```bash
pip install flask           # يحتاج أيضًا الأمر openssl (موجود غالبًا)
python control_server.py
```

عند أول تشغيل ينشئ:
- بياناته في مجلد `control-data/` (الرموز، المفاتيح المختومة، الأسرار، الشهادة) — احفظ هذا المجلد.
- شهادة TLS موقّعة ذاتيًا (لا تحتاج شهادة من جهة خارجية).
- كلمة مرور المالك (تُطبع مرة واحدة إن لم تحدّدها) ورابطين يُطبعان:
  - **لوحة المالك:** افتحها في المتصفح وادخل بكلمة المرور.
  - **رابط التطبيق:** انسخه كاملًا وضعه في التطبيق (إعداد الخادم). يحمل بصمة شهادة الخادم، فلا يقبل التطبيق خادمًا آخر.

## الإعدادات (كلها اختيارية، متغيّرات بيئة)

| المتغيّر | الغرض | الافتراضي |
|---|---|---|
| `CONTROL_DATA` | مكان البيانات والشهادة والأسرار | `./control-data` |
| `CONTROL_HOST` | عنوان الاستماع | `0.0.0.0` |
| `CONTROL_PORT` | المنفذ | `8443` |
| `CONTROL_PUBLIC_HOST` | الاسم الذي يظهر في الروابط | عنوان الجهاز |
| `CONTROL_ADMIN_PASSWORD` | ضبط/تغيير كلمة مرور المالك | تُولَّد وتُطبع مرة |

على المنفذ 443 يظهر الرابط بلا رقم منفذ. خلف وكيل عكسي (nginx) مرّر المنفذ كما هو، وأبقِ تثبيت الشهادة (التطبيق يتحقق من بصمة شهادة هذا الخادم نفسه).

## واجهة التطبيق (للرجوع)

كلها `POST` إلى `/<app-secret>/<action>` بصيغة JSON، والردّ `{"ok": true, ...}` أو `{"ok": false, "error": "..."}`:

- `activate` — `{code, device}` ← يتحقق من الرمز ويعيد `{token, engine}`.
- `check` — `{token}` ← `{active}` (التطبيق يتحقق عند كل فتح؛ لو أوقفت الرمز يُقفل فورًا).
- `comment` — `{token, text, image?, voice, manner, before}` ← يكتب الرد بالمفتاح المُفعّل ويعيد `{comment}`.

التعليق يُكتب بنفس أسلوب التطبيق تمامًا (المنقول من `gg_app.py`): عامية سعودية، بلا تشكيل ولا فواصل، وبطول محدود.
